Argbed

A hardened, private, minimal, modular kickstart for Fedora

A kickstart is the file that tells Fedora's installer what to do. Argbed assembles one from small modules, and what it installs is Fedora itself, from Fedora's own packages.

Not a distro

Every package in the base comes from Fedora's own repositories, installed by Fedora's installer and updated with dnf: no custom package manager, no repackaging, no repository of its own. After the install the system is Fedora, configured by the modules.

Hardened

  • LUKS2-encrypted root filesystem.
  • Signed unified kernel images boot through shim and systemd-boot under a key generated at install time; with Secure Boot on, nothing unsigned boots. GRUB is not in the boot path: no boot entry, no configuration.
  • SELinux enforcing, with confined users and a locked root account.
  • Default-drop nftables for inbound and outbound traffic, loaded before the network comes up on every boot.
  • Updates installed at boot, before login, or by hand with dnf at any time.

Private

  • systemd-networkd and iwd, not NetworkManager, with randomized MAC addresses and anonymized DHCP.
  • DNS is a static file naming pinned resolvers, Cloudflare's by default; the firewall passes port 53 to no other address, and DHCP-provided DNS is ignored.
  • Microphones and cameras disabled: no capture node in the audio server, and their device nodes closed to every unprivileged process.
  • Bluetooth pairable only inside a bluetoothctl session and never discoverable unless switched on.
  • Firefox hardened by policy: telemetry and sync off, third-party cookies rejected, HTTPS only, uBlock Origin, DuckDuckGo as the search engine.

Minimal

  • No @core: every package is named in a module, a hard dependency of one, or one of the installer's own additions. Weak dependencies are off.
  • A sway Wayland desktop. No wallpaper and no graphical settings tool: the base's only graphical programs are sway with a bar and a lock screen, a terminal and Firefox.

Modular

  • Each concern lives in its own module under ks.d/, with optional ones under optional/: the packages and their configuration together.
  • The build script assembles the active modules in order, substitutes the machine's values and, with pykickstart installed, validates the result: one kickstart file for Fedora's network installer.
  • An optional module is enabled by copying it into ks.d/ and disabled by taking it out. A base module such as Bluetooth comes out the same way; the README's base section names the packages the system cannot do without.
  • Anything else installs with dnf from Fedora's repositories.

The README in the repository is the documentation, from the build and the USB stick to Secure Boot enrollment and the trade-offs.
